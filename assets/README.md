# Publication assets

`screenshots/` contains actual Streamlit viewport captures taken on 2026-10-19.
The images show the default 50-product cohort and seven-day lead / 14-day initial
cover context. The forecast screenshot uses the final holdout view; the demand
screenshot uses training history. Charts and values are not redrawn.

The [capture manifest](screenshots/manifest.json) records dimensions, SHA-256 hashes, capture context, and the app
source fingerprint. The [gallery](../docs/DASHBOARD_GALLERY.md) supplies captions.
These images contain aggregate results and selected product diagnostics, not
source file downloads. Raw data and full generated marts remain excluded from Git.
